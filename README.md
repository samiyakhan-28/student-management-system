# Student Management System

A beginner-friendly Student Management System built using Python to practise the fundamentals of Object-Oriented Programming (OOP).

## 📌 About the Project

This project represents a basic student management system that stores student information and allows student details to be displayed and updated. It was created as a hands-on project to strengthen my Python programming skills.

## ✨ Features

- Create student objects with individual details.
- Store student name, roll number, branch, and semester.
- Display student details.
- Update a student's semester.
- Manage multiple student objects using a Python class.

## 🛠️ Technologies Used

- **Language:** Python 3
- **Concepts:** Classes, Objects, Constructors, Methods, and Object Attributes
- **Editor:** Visual Studio Code

## ▶️ How to Run

1. Install Python 3 on your computer.
2. Clone this repository:

   ```bash
   git clone https://github.com/samiyakhan-28/student-management-system.git
   ```

3. Open the project folder:

   ```bash
   cd student-management-system
   ```

4. Run the Python program:

   ```bash
   python3 Student_management_system.py
   ```

   On Windows, you can also try:

   ```bash
   python Student_management_system.py
   ```
